# Responsible use

- This project outputs probabilities for research and education. It is not financial advice.
- No prediction system guarantees profit. Bookmakers set odds professionally and include a margin.
- Never bet money you cannot afford to lose. Never chase losses. Set a bankroll and stake limits
  (the value engine's fractional Kelly exists precisely to enforce this).
- Betting can be addictive. If it stops being fun, help is available — e.g. BeGambleAware.org (UK),
  Gamblers Anonymous, and local support services in Nigeria (Bet9ja/SportyBet both carry
  responsible-gambling pages and self-exclusion tools).
- Check that betting and the specific bookmaker are legal and licensed where you live.
- Under-18s must not bet.
